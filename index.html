About Me

사용자 중심의 집요함으로 서비스의 본질을 설계하는 프로덕트 디자이너

문제를 끝까지 파고들어 해결책을 찾아내는 집요함을 바탕으로 꾸준히 성장해왔으며, 새로운 방법을 배우고 사용자의 흐름에 적용하는 데 열정을 가지고 있습니다.

개발 동아리 활동을 통해 팀원과 긴밀히 협업하며 사용자 경험의 구조를 설계하고 프로젝트를 주도적으로 출시까지 완성하는 경험을 쌓았습니다. 또한, 스타트업에서 개발자로서 기술적 난제를 해결하는 데 그치지 않고, 사용자의 행동 구조를 다시 설계하는 BM 전환을 기획·제안했습니다.

계속하여 데이터·관찰·실험으로 디자인 결정의 근거를 단단히 만들고, 빠른 서비스 확장 속도에 맞춰 팀과 함께 기민하게 가설을 검증하며 성장하고 싶습니다. 데이터를 기반으로 검증하고 개선하며, 사용자에게 실질적 가치를 전하는 디자이너가 되고자 합니다.

03

데이트로드 — 코스 중심의 데이트 코스 공유 서비스 데모데이 최우수상

메인 화면의 빈 화면 노출 문제를 발견해 스켈레톤 뷰와 로딩 인디케이터의 노출 규칙을 새로 설계하고, Figma 커스텀 디자인 + iOS 구현 시연으로 출시까지 반영

기간
2024.07 – 2024.11 (5개월)
역할
iOS 파트 리드
사용 기술
Swift · iOS · Figma · Notion

본인 기여

  • 메인 화면에서 다량의 데이터를 불러올 때 빈 화면이 노출되어 앱이 멈춘 것처럼 보일 수 있다는 문제를 직접 사용 관찰에서 발견
  • 스켈레톤 뷰와 로딩 인디케이터를 동시에 노출하는 첫 안에서, 매번 둘을 함께 보여주면 짧게 스치는 데이터 변경에서도 사용자 흐름이 끊긴다는 점을 인지하고 노출 규칙을 단계 분리
  • 최종 규칙 — 첫 데이터 로딩에서는 스켈레톤 + 로딩 인디케이터를 함께 노출, 이후 데이터 변경 시에는 로딩 인디케이터만 노출
  • 개발 환경 기본 스켈레톤이 메인 뷰 레이아웃과 맞지 않아, Figma로 메인 뷰의 레이아웃에 맞춘 스켈레톤을 직접 커스텀 디자인
  • 디자인 시안 전달에서 멈추지 않고 iOS 단까지 직접 구현해 작동하는 형태로 팀에 시연, 팀의 의사결정을 끌어냄
  • iOS 파트 리드로 다른 직군과의 협업 및 출시 프로세스 주도

성과

  • 제안한 노출 규칙이 그대로 반영되어 출시되어 데모데이 시연에서 로딩 UX에 대한 긍정적 피드백 확보
  • Active Users 2,400+ 달성
  • SOPT 34기 데모데이 최우수상 수상
